# 浏览器地址栏测试清单

将下面 `你的IP` 换成实际地址（例：`47.245.108.129`），`你的钱包` 换成要测的地址。

**注意：**

- 地址栏只支持 **GET**，下面全部是 GET。
- **链上事件同步**类接口（`get_box_*_event`）可能 **1～3 分钟** 才返回，浏览器会一直转圈，属正常现象；急用请用 `curl --max-time 200` 在服务器上测。
- 若返回 **502/504**，先看 Docker 里 `api` 是否 **Up**，再看 Nginx/防火墙。

---

## 1. 基础（应秒开）

| 说明 | URL |
|------|-----|
| 健康检查 | `http://你的IP:8003/health` |
| 盲盒数量（链上） | `http://你的IP:8003/api/get_box_all` |
| 铸造同步诊断 | `http://你的IP:8003/api/debug_mint_sync` |
| 从合约 view 补 `nft_minted` | `http://你的IP:8003/api/sync_mint_from_contract` |

## 2. 盲盒 / 市场（需参数）

| 说明 | URL |
|------|-----|
| 某地址盲盒列表（你已验证） | `http://你的IP:8003/api/get_address_box?address=你的钱包&page=1&numTwo=0&numThree=1&openStatus=0&num=0` |
| 二级市场列表 | `http://你的IP:8003/api/get_market_box_list?page=1&numTwo=0&num=0&numThree=0` |
| 全站统计（时间范围可改） | `http://你的IP:8003/api/get_all_info?start=0&end=9999999999` |
| 分佣待发列表 | `http://你的IP:8003/api/referral_pending?page=1&pageSize=20` |

参数含义见 `docs/API调用文档.md`（`num`、`numTwo`、`openStatus` 等）。

## 3. 链上事件同步（慢，浏览器易卡住）

| 说明 | URL |
|------|-----|
| 铸造事件 → DB | `http://你的IP:8003/api/get_box_mint_event` |
| 开盒事件 | `http://你的IP:8003/api/get_box_open_event` |
| 挂单 | `http://你的IP:8003/api/get_box_list_event` |
| 撤单 | `http://你的IP:8003/api/get_box_unlist_event` |
| 二级市场购买 | `http://你的IP:8003/api/get_box_buy_event` |
| NFT 转账 | `http://你的IP:8003/api/get_box_transfer_event` |
| 用户注册事件 | `http://你的IP:8003/api/get_user_r_event` |
| 兑换/交易事件 | `http://你的IP:8003/api/get_exchange_event` |

无 query 也可调；**耗时长**，不建议用地址栏反复点，用 **cron + sync-events.sh** 更稳。

---

## 5. 快速判断有没有问题

1. `/health` → `{"status":"ok"}`  
2. `/api/get_address_box?...` → `count` 与 `list` 条数一致，无重复 tokenId  
3. `/api/get_box_all` → 有 `newLength` / `openLength`  
4. 慢接口：若长期无响应，到服务器执行 `docker logs requesteth-api-1 --tail 30` 看是否在扫块  

---

## 6. 已知「不算故障」的现象

- `debug_mint_sync` 里 **FilterLogs limit exceeded**：免费 RPC 常见，依赖 **`sync_mint_from_contract`** 或付费节点。  
- 事件类接口返回空 `{}`：可能当前区块范围内无新事件或同步未完成。
